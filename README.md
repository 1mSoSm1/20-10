# 🌸 Hành Trình Đóa Hoa Bản Sắc 3D — Chúc Mừng 20/10 🌸

Dự án thiệp chúc mừng và trắc nghiệm bản sắc 3D tương tác chào mừng ngày Phụ nữ Việt Nam 20/10.

## ✨ Tính năng nổi bật

- **Mô hình 3D Nghệ Thuật (Three.js)**:
  - Đóa Hoa Hồng Lụa 3D đa tầng cánh nở bung dần theo từng câu trả lời trắc nghiệm (bloom progress).
  - Thẻ bài Tarot Diorama 3D Hologram phản chiếu ánh kim hoàng gia (Rose Gold Bezel & Velvet backdrop).
  - Tương tác nghiêng xoay 3D trực quan theo chuột trên máy tính và cảm ứng vuốt trên điện thoại.
- **Trắc nghiệm tâm thức 10 câu hỏi**:
  - Giao diện Constellation Star-bar & 4 lá bài Tarot Arcanum với 24 bộ Icon Vector Vàng Kim (Mystical Gold SVG) vẽ tay sắc nét.
- **Hệ thống 18 loài hoa bản sắc**:
  - Tạo hình Canvas 2D nghệ thuật độ phân giải cao kết hợp hiệu ứng hào quang, vòm trăng khuyết và bảng tên khắc vàng.
  - Phân tích khí chất và lời chúc được cá nhân hóa theo tên người nhận.

## 🚀 Trải nghiệm trực tiếp

Chỉ cần mở file `index.html` trực tiếp trên bất kỳ trình duyệt hiện đại nào (Chrome, Edge, Safari, Firefox), hoặc kích hoạt **GitHub Pages** trong phần Settings của repository để truy cập trực tuyến.
